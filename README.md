# Dotfiles
This repo contains the dotfiles for my system

## Installation
```sh
$ git clone git@github.com/haschad/dotfiles.git ~/dotfiles
$ cd dotfiles
$ chmod +x install.sh
$ ./install.sh
```

## AppImage Apps
- [go-appimage](https://github.com/probonopd/go-appimage)
- [krita](https://krita.org/en)
